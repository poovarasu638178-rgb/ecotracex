# EcotraceX — Carbon Footprint Awareness Platform

**PromptWars Virtual 2026 - Challenge 3 Submission**
**Built by Poovarasu S**

EcotraceX is a modern, ultra-lightweight, and fully responsive Carbon Footprint Awareness Platform built to help users track, understand, and reduce their environmental impact. 

## 🏆 Hackathon Evaluation Criteria Alignment

*   **Code Quality & Efficiency:** The entire application has been aggressively optimized into a **single, zero-dependency `index.html` file**. This architectural decision ensures lightning-fast load times, eliminates build steps, and keeps the entire repository size far below the **10 MB limit** required by the hackathon. 
*   **Accessibility (A11y):** Built with strict semantic HTML5, comprehensive `aria-*` attributes, full keyboard navigation support, skip links, and a dedicated High Contrast mode toggle to ensure the platform is usable by everyone.
*   **AI Integration:** Seamlessly integrates with the **NVIDIA Llama-3 API** to provide dynamic, personalized, and actionable carbon reduction insights based on the user's specific footprint profile.
*   **Problem Statement Alignment:** Directly addresses Challenge 3 by providing an IPCC-aligned footprint calculator, dynamic progress tracking, and gamified "Eco Hero" milestones.

## 🚀 Key Features
*   **IPCC-based Calculator:** Accurate emission factors for transport, diet, energy, and consumption.
*   **Interactive Dashboard:** Real-time visualizations and benchmarking against national and global averages.
*   **Mobile-First Design:** Fully responsive UI with a biophilic aesthetic and modern typography (Plus Jakarta Sans + Inter).
*   **Gamification:** Streaks and milestone badges to encourage continuous logging and behavioral change.

## 🛠️ Setup & Deployment
Because EcotraceX is built as a highly optimized, vanilla HTML/CSS/JS application, there are no complex build steps or package managers required.
1. Clone the repository.
2. Open `index.html` in any modern web browser.
3. Deploy instantly to any static hosting provider (Vercel, Netlify, GitHub Pages).

*(Note: To enable AI Insights, ensure the NVIDIA API key is configured correctly in the environment).*
